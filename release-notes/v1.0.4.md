## Kinglet v1.0.4

### 修复
- **`.md` 文件图标恢复成文档图标** — v1.0.3 重做图标（修任务栏发糊那次）时，`.md` 专属文档图标 `icons/md-file.ico` 误用了软件图标的源图，两个 `.ico` 变成同一份字节，资源管理器里所有 `.md` / `.markdown` 显示成了 Kinglet 的应用 logo。现已从 `icons/md-file-src.png` 重新生成并逐尺寸校验（`.md` 图标与应用图标的哈希必须不同）
- **更新弹窗标题不再显示 `{version}`** — 之前点「检查更新」标题会原样显示 `发现新版本 v{version}！`（字符串里有占位符但全项目没有插值逻辑）。现标题为固定文案「发现新版本」，版本号仍在标题下单独一行显示；同段无引用的死字符串 `update_available_body` 一并删除
- **「检查更新」的提示换成应用内面板** — 「当前已是最新版本」「浏览器模式下无法检查更新」「检查更新失败」「更新失败」原先弹系统原生 `alert()`，看着像浏览器警告。现在是与更新弹窗同一套样式的居中面板（同一遮罩 / 圆角 / 边框 / 按钮，宽 320px，单按钮「知道了」），Esc、右上 ×、点遮罩、点按钮均可关闭

> 提示：若资源管理器里旧图标仍在，清一次图标缓存（`iconcache*` / `thumbcache*`）或注销重登即可。
